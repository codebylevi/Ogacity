# Ogacity website

A responsive, static rebrand of the former ManGO landing page for Ogacity — Digital Local Commerce.

## Deploy on Vercel from your phone
1. Extract `ogacity-website.zip` on your phone, or use the files directly.
2. Upload the project files and `assets` folder to a GitHub repository. Keep `index.html`, `styles.css`, and `script.js` in the repository root.
3. In Vercel, choose **Add New → Project**, import the repository, and deploy.
4. In Vercel project settings, add `ogacity.com` and follow the DNS instructions shown there. Your domain registrar must contain the exact DNS records Vercel provides.

No build command or output directory is required for this static HTML website.
